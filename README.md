4. Poistive, Negative and Zero

PSEUDOCODE

START
INPUT num
IF num > 0 THEN
  DISPLAY "Positive"
ELSE IF num < 0 THEN
  DISPLAY "Negative"
ELSE
  DISPLAY "Zero"
END IF
END

 6. Average Temperature Calculation

  sum = sum + temp
